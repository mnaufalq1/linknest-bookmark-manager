## Tentang Projek Ini

Projek ini adalah projek untuk menyimpan bookmark dalam bentuk web apps yang dimana user bisa menyimpan, mengedit, menghapus, menandai sebagai favorit, menandai sebagai arsip, dan mencari bookmark. Untuk framework yg digunakan di projek ini adalah Next.js 16 menggunakan App Router. Bahasa yg digunakan untuk mengetik kode dan dokumentasi adalah Bahasa Indonesia. Untuk styling menggunakan Tailwind CSS. Untuk database menggunakan Prisma 7. Database disimpan secara lokal menggunakan PostgreSQL. Untuk component library tidak menggunakan library shadcn UI.


## Peraturan untuk AI Agent yang akan mengerjakan proyek ini

1. Selalu menjawab dan berkomunikasi menggunakan Bahasa Indonesia
2. Selalu menulis komentar dan documentation menggunakan Bahasa Indonesia
3. Selalu menggunakan Bahasa Indonesia dalam kode
4. Saat bekerja dengan Next.js, wajib membaca dokumentasi Next.js terbaru
5. Jika ada perintah yg masih ambigu maksudnya, tanyakan kembali ke user, dan jangan sampai menghalu membuat kode yg tidak sesuai
6. Versi Prisma yg digunakan adalah Prisma 7, Jadi selalu perhatikan dokumentasi Prisma 7 dan jangan sampai mengubah versinya
7. Package Manager yg digunakan di projek ini adalah Pnpm bukan Npm, Yarn, atau lainya, jadi selalu menggunakan Pnpm saat ingin menjalankan package dan dependencies, contoh "pnpm install" bukan "npm install" dan seterusnya
